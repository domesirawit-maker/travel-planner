# ✈️ Travel Planner · HK · Shenzhen · Guangzhou

A single-file React travel planning app — no build tools, no dependencies, just open and go.

## Features

- 🗺️ Multi-trip management with day-by-day itineraries
- 📍 Place cards with Google Maps & Amap (高德) deep links
- 🖼️ Image uploads per place
- 🔍 Full-text search across trips and places
- 🌙 Dark mode
- 💾 Auto-saves to `localStorage` — data persists across sessions
- 📤 Export / Import trips as JSON
- 📱 Fully responsive

## Usage

Open `index.html` in any modern browser — or visit the live site below.

## Live Site

Deployed via GitHub Pages: `https://<your-username>.github.io/travel-planner`

## Tech

Built with React 18 (via CDN), no bundler required.
